## 🚀 Nasıl çalıştırılır?

Bilgisayarında Python 3 kurulu olmalı. Depoyu indirdikten sonra terminali depo klasöründe açıp istediğin dosyayı çalıştır:

```bash
python oyunlar/sayi_tahmin_oyunu.py
```

Windows'ta `python` komutu çalışmıyorsa `py` komutunu dene:

```powershell
py matematik/fibonacci.py
```

Programlar girişlerini terminalden alır. Her biri bağımsız çalışır; ek paket kurmana gerek yoktur.
